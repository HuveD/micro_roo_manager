이번 작업 사항과 관련하여 테스트 시나리오를 보완할 부분이 있는지 검토하고, 프로덕트의 품질을 높입니다.

다음 단계를 따라주세요:
1. 현재 작업 내용 분석
2. 현재 구현된 테스트 스위트 분석
3. 테스트 실행하여 회귀가 발생했는지 확인
4. 테스트 실행 결과를 분석하여 불필요하거나 가치가 낮은 테스트 스위트 정리
5. 변경 로직과 부실한 테스트 시나리오를 파악하여 테스트 개선
6. 전체 테스트 PASS 시키기
7. 결과 요약

주의사항:
- 중복 테스트 검증이 발생하지 않도록 합니다.
- 테스트 케이스의 명칭을 영문 스네이크 케이스로 직관적이게 설정합니다.
