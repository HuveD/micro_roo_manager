## 검토 범위

1. **계획 실행 검증** (plan-output.md 존재시)
   - TODO 완료 상태
   - 계획된 문서 작성 여부

2. **코드 품질 검증**
   - **크기 제한**: 파일 500줄, 메서드 15줄 (문서 제외)
   - **단일 책임 원칙**: 하나의 역할만 수행
   - **중복 제거**: 동일 로직 재사용
   - **설계 원칙**: SOLID, DRY, KISS

3. **문서-코드 동기화** (docs/ 존재시)
   - interfaces: API 명세 ↔ 실제 구현
   - design: 설계 원칙 ↔ 코드 구조
   - logic: 비즈니스 규칙 ↔ 도메인 코드
   - standards: 코딩 표준 ↔ 코드 품질


## 작업 타입별 핵심 검증

- **핫픽스**: 최소 수정, 회귀 테스트
- **기능 추가**: 요구사항 충족, 기존 기능 영향 없음
- **아키텍처 변경**: 설계 문서 일치, 단계별 구현
- **표준 구축**: 실용성, 팀 적용 가능성
- **리팩토링**: 동작 보존, 품질 개선
